## 📋 Descripción General

El **Simulador de Sanciones Aduaneras** es una herramienta interactiva diseñada para **analizar, calcular y prevenir sanciones derivadas de incumplimientos aduaneros** en operaciones de comercio exterior.  

El sistema permite a agentes de aduana, importadores, exportadores y asesores logísticos **simular escenarios reales** con base en las disposiciones normativas vigentes (como el Decreto 1165 de 2019 y la Resolución 046 de 2019 en Colombia), proyectando el impacto económico y operativo de diferentes infracciones.

---

## 🎯 Objetivo del Proyecto

Optimizar la **gestión de cumplimiento aduanero** mediante una plataforma que:
- Evalúa infracciones según parámetros definidos (tipo de error, valor FOB, régimen, reincidencia, etc.).  
- Calcula automáticamente la sanción estimada en valores monetarios y porcentuales.  
- Ofrece recomendaciones de mejora o prevención.  
- Permite registrar casos para análisis histórico o capacitación.  

---

## ⚙️ Funcionalidades Principales

- 🔍 **Simulación de casos aduaneros:** selección de tipo de infracción, valor declarado, error cometido y reincidencia.  
- 💰 **Cálculo automático de sanciones:** en base a tablas normativas.  
- 📊 **Panel analítico:** gráficos y resúmenes de los casos registrados.  
- 🧠 **Módulo educativo:** explicación normativa y ejemplos prácticos.  
- 🧾 **Exportación de reportes:** en PDF o Excel para revisión interna o capacitación.
